## Private R&D namespace

The private side contains a large `universal-*` family spanning moderation, multilingual classification, LLM guardrails, bias detection, GDPR/DSA reporting, dispute resolution, phishing analysis, decentralized identity, deepfake-audio detection, offline model routing, local AI, private code review, dependency management, music tooling, accessibility, web tooling, civic tooling and resource discovery.

These repositories are **R&D inventory**, not public claims of production readiness. Their existence is useful as a capability map while implementation maturity varies.

## Status vocabulary

Use these labels consistently when documenting projects:

- **IDEA** — concept / reserved namespace.
- **LAB** — experiment or research.
- **PROTO** — functioning prototype.
- **BETA** — usable but still changing.
- **PROD** — production-oriented.
- **ARCHIVED** — historical or superseded.

## Principle

Do not hide the experimental history. Make the relationships and maturity explicit.

The ecosystem is allowed to be broad: **AI + software + automation + music + visual computing + trust/safety + human experiences** are different surfaces of the same creative-technical practice.
