Criterio de publicación

Un producto entra en el escaparate cuando la superficie pública, el contenido y la evidencia técnica no se contradicen. El resto del ecosistema permanece fuera hasta cumplir el mismo estándar.

  • NarrativaEl usuario entiende qué es, para quién existe y qué puede recorrer.
  • WebHTML semántico, responsive, accesible y sin dependencias accidentales.
  • PruebaInstalación, tests, build y comprobaciones documentadas en el repositorio.
  • LímiteLo privado, experimental o no verificado queda fuera del escaparate.
Rama main limpio y alineado con origin/main.
HTML Portada conforme al verificador local, sin recursos externos.
Fuente README con instalación, pruebas, build y runtime documentados.
