## PRD
El usuario solicita actualizar y desplegar el perfil y finalizar los proyectos.
Esta autorización sustituye para esta ejecución la restricción anterior de no push
ni publicación. Se mantienen privacidad, preservación del trabajo y validación.

## SRS / Diseño
Publicar la portada profesional y las utilidades existentes desde docs; conservar
Senior y los proyectos originales, sin exponer archivos operativos privados.
La misma salida estática debe funcionar en GitHub Pages y Vercel.

## ADR
Vercel tenía un builder de package.json y una ruta hacia site, mientras el
package.json empaqueta una aplicación Electron. El perfil web es estático y vive
en docs. Usar salida docs sin instalación/build evita ejecutar un build Windows
para publicar HTML. No cambiar las funciones de la aplicación de escritorio.
