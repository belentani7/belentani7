5 · Deduplicación: 434 → 115

El 07-11 se ejecutó la deduplicación planificada de la cuenta: 314 repositorios eliminados con gh repo delete (0 fallos), con lista por familias y registro completo. Quedan 120 en la cuenta: los 115 keepers y 5 excluidos por contener audio/voz privado.

Red de seguridad (tres capas): ① los 314/314 conservan clon local verificado en _audit\work\repos; ② 315/321 bundles git generados el 07-11 en workspace\archivo\bundles-dedup-20261107; ③ ventana de restauración de GitHub hasta el 5 de febrero de 2027 (Settings → Deleted repositories).

Riesgo residual declarado: 6 clones no generaron bundle (objetos corruptos o vacíos en origen) y la cuenta quedó 2 clones por debajo del total teórico (321 = 314 borrados + 5 audio + 2 renombrados); ambos listados en el estado del lote de bundles.

8 · Sesiones de agentes de código

Análisis forense de 74 sesiones de CLI coders (22.276 líneas): 911 afirmaciones de éxito, de las cuales 128 sin evidencia; 92 comandos destructivos o de publicación (git reset --hard 48, git push 31, git commit 8, rm -rf 5); 661 resultados fallidos con 26 fallos ignorados y claim posterior; 4 secretos redactados. Sesión de mayor riesgo: 37,6/100. Los scripts con capacidad de aplicar cambios masivos (ship.py, push_all.py, clone_all.py, push-final.py…) quedaron bloqueados a propósito en el toolkit.
