I build AI-native products end to end: the agent runtime, the tooling around it, the interface people actually use, and the deployment that keeps it alive. Most of my work runs on infrastructure I can afford — local models, free tiers, static hosting — because a product that only exists behind a corporate budget is not a product.

I came to engineering from seven years of Trust & Safety at TELUS Digital and multilingual support for Inditex, which is where I learned that the hard part of software is rarely the code; it is deciding what should happen when it fails.

## What I actually do

- **Agent infrastructure.** Skill routing, model selection, MCP integration and orchestration that survives Windows, missing GPUs and free-tier quotas.
- **AI products with a price and a policy.** Encryption, GDPR, one-time payments, no dark patterns, no telemetry.
- **Open education.** Multi-language curricula built to work offline, with accessibility as a requirement rather than a phase.
- **Creative engineering.** 3D, audio and generative work where the code is part of the artwork.

## How I work

- **Evidence over claims.** A feature is done when a command, a URL or a test says so — not when the README says so.
- **Tests before refactors.** Reproduce the failure, then fix the cause.
- **Accessibility and reduced motion by default,** not as a late audit.
- **Zero third-party tracking** on anything I ship.
- **PT > ES > EN > CA.** I write and ship in all four.
