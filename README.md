## How I build

I prefer systems that are inspectable and recoverable: explicit boundaries, local-first/offline-first when useful, minimal personal-data collection, clear quickstarts, reproducible builds, security checks and accessible interfaces. I use AI as an engineering component, not as a substitute for product architecture.
