## EN

I am Belentani, a frontend developer and digital experience creator working across product, visual narrative and knowledge systems.

NOIACORE is my creative and technical lab: a practice focused on turning complex information into clear, accessible and useful interfaces.

### Capabilities

- React and TypeScript for maintainable web applications.
- Three.js and WebGL for real-time visual experiences.
- GSAP and ScrollTrigger for purposeful motion and interaction.
- Accessibility across navigation, reading, motion and visual preferences.
- Educational platforms, multilingual resources and guided tools.

### Selected public work

- [Manos Abiertas](https://github.com/belentani7/manosabiertas): an educational and guidance platform built with Next.js, React and TypeScript, including accessibility controls.
- [Oculus TV](https://github.com/belentani7/Oculus-Tv): a multilingual repository of books and educational audiovisual materials.
- [heyduck](https://github.com/belentani7/heyduck): a visual frontend for a music studio, using GSAP and ScrollTrigger.
