## Selected systems

### 01 — meta-skill
**Offline decision support for agent workflows.** Rules-based task/model recommendations, explainable signals and abstention for uncertain requests. Does not execute model inference or guarantee cost savings.  
[Source](https://github.com/belentani7/meta-skill) · Python · TypeScript · evaluation lab

### 02 — profile-lint
**Evidence-minded developer tooling.** A Python CLI to check profile READMEs for missing alt text, broken paths, remote widgets and unsupported claims.  
[Source](https://github.com/belentani7/profile-lint) · Python · CLI · GitHub Actions

### 03 — secure-t
**Responsible security education.** Open-learning materials on cybersecurity and responsible AI. Published content does not itself establish learning outcomes or deployed platform readiness.  
[Source](https://github.com/belentani7/secure-t) · TypeScript · Next.js

### 04 — kepler
**Measurable WebGL engineering.** A single-file WebGL2 galaxy with documented benchmark conditions on Intel UHD 620. The repository reports 200,000 particles at 59.9 fps and a 17.5 ms p95; higher counts show increasingly uneven frame times. These are author-reported measurements.  
[Source](https://github.com/belentani7/kepler) · WebGL2 · GLSL · JavaScript

### 05 — Cruzando el charco
**Accessible, multilingual information.** A community resource guide for LGBTQ+ migrants in Barcelona and Sitges, designed to keep essential information usable without JavaScript. Resource freshness requires ongoing review.  
[Source](https://github.com/belentani7/Cruzando-el-charco) · HTML · accessibility

### 06 — belentani.es
**Creative-technology case study.** An interactive experience built around music and narrative using web graphics. It demonstrates interactive design; the artist project is separate from my professional engineering profile.  
[Source](https://github.com/belentani7/belentani.es) · Next.js · Three.js · WebGL
