## Cómo trabajo

1. **Contract before code.** Si el modo de fallo no está escrito, no está diseñado.
2. **Evidence over adjectives.** Cada afirmación enlaza a un repo, un test o una medición — o se etiqueta como no verificado.
3. **Deterministic before probabilistic.** Reglas y esquemas primero; el modelo es la última milla, no la base.
4. **Ship the interface.** Un sistema que nadie puede operar no está terminado.

Qué significa para una colaboración: obtienes los modos de fallo y la ruta de verificación en la primera semana, y una demo solo cuando ambos se mantienen. Si un plazo obliga a una afirmación que no puedo testear, prefiero cortar la afirmación.
