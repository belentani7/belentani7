A local, explainable router for agent tasks. It recommends a tier, estimates cost only when rates exist, and abstains when confidence is low instead of inventing an answer. It never calls a model and sends no prompt to a provider.

## How I work

1. **Contract before code.** If the failure mode is not written down, it is not designed.
2. **Evidence over adjectives.** Every claim links to a repo, a test or a measurement — or it is labelled unverified.
3. **Deterministic before probabilistic.** Rules and schemas first; the model is the last mile, not the foundation.
4. **Ship the interface.** A system nobody can operate is not finished.

What that means for a collaboration: you get the failure modes and the verification path in the first week, and a demo only once both hold. If a deadline forces a claim I cannot test, I would rather cut the claim.
