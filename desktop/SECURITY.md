# Security Policy

## Supported versions

The latest tagged release is the supported version.

## Reporting a vulnerability

Do not disclose vulnerabilities in a public issue. Send a private report to the repository maintainers through GitHub Security Advisories once the repository is published. Include the affected version, reproduction steps, impact, and a minimal proof of concept. Never include live API keys or personal data.

Bellentani is a local developer tool. Running arbitrary commands or agents on a workspace can modify files and access credentials available to the operating-system account. Use isolated workspaces and review PVC-U decisions before approving high-risk actions.
